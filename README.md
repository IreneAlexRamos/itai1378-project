\## Problem Statement



Many pet owners struggle to correctly identify dog types, which can affect their understanding of a dog's care, behavior, and needs. Misidentification between similar-looking breeds, such as French Bulldogs and Pugs, is common.



\## Solution Overview



Gnasher Group will develop a computer vision application that analyzes an uploaded image of a dog and classifies it into one of the seven AKC groups: Sporting, Hound, Working, Terrier, Toy, Non-Sporting, or Herding. The application will provide the predicted group and useful information to help users better understand the type of dog they are viewing.
